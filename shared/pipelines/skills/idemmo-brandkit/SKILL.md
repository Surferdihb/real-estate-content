# IDEMMO Master Branding Guideline

Use this skill as the source of truth for IDEMMO content. IDEMMO is a Luxembourg real-estate reference based in Foetz, with independent agents, IDEHUB/Academy support, and agent commissions commonly communicated as 50–85%.

## Master template

Use `brand-assets/idemmo/14-Day Campaign Test v1.0/IDEMMO-Academy-Post-04-06.mp4` and its preview/source as the visual master. Adapt content inside this composition; do not invent a new layout. The master is a dynamic 8-second, 1080×1920 (9:16) HyperFrames composition.

Every approved variant must preserve the master’s: top-left official IDEMMO full logo; `04 / 06`-style gradient chapter pill; subtle navy grid; pale yellow/green/cyan upper-right wash; lower orange → yellow/green → cyan organic form; Academy eyebrow; navy/gradient hero typography; white rounded academy card; three colored numbered rows; bottom-right IDEMMO house icon; white `Envoyer “AGENT”` CTA; and Foetz footer.

## Visual identity

- Format for Reels, TikTok, Shorts and Stories: 1080×1920, 9:16.
- Base: warm near-white `#fbfaf7` with a very subtle navy grid when appropriate.
- Navy ink: `#102b45`.
- Gradient order must remain pink → orange → yellow/green → cyan: `#e52d78`, `#ff8a18`, `#80c84b`, `#12b8d7`.
- Use the master’s large soft organic forms: pale yellow/green/cyan wash upper-right and orange → yellow/green → cyan lower-left form. Do not substitute unrelated gradients.
- Use rounded white cards, soft shadows, thin warm-gray dividers, and generous whitespace.
- Logo placement is top-left with correct aspect ratio; never stretch or distort it.
- Chapter pills use the multicolor gradient with white text (`04 / 06`, etc.).
- Headline hierarchy: large navy sans-serif; accent words use the IDEMMO gradient. Eyebrows are uppercase, letter-spaced, and gradient or pink.
- Keep copy in French unless the user asks for another language. Preserve accents and apostrophes.

## Motion/video rules

For video, use HyperFrames rather than a static MP4. Animate the logo/chapter first, then eyebrow, headline lines, subhead, academy card, rows, icon and CTA with short eased entrances. Keep the composition 8 seconds by default and make the first and last frames visually legible.

Never add the multicolor play button shown in the reference artwork. The bottom-right IDEMMO house icon is allowed and is not a play button. Do not flatten a requested dynamic composition into a still image; render the HTML timeline to MP4 and verify motion at multiple timestamps.

## Content-format rules

- Hero title, supporting description, and card subjects must be specific to the day’s topic; never repeat the generic master copy across all variants.
- Keep the master’s line hierarchy: gradient/colored hero lead, navy continuation, then a topic-specific subhead directly below.
- Keep the master’s card geometry and use three topic-specific rows. Use the standard colors: `01` pink, `02` orange, `03` green.
- Post A can be a static/carousel adaptation, but it must retain the master’s visual system. Post B must be rendered as an animated HyperFrames video.
- The play button visible in source/reference artwork is excluded. Never add it to variants.

## Academy card pattern

Use the approved three-row card when relevant:

1. `01` Apprendre les fondamentaux (pink)
2. `02` Construire votre méthode (orange)
3. `03` Grandir avec le Hub (green)

Typical CTA: `Envoyer “AGENT”`. Typical footer: `Foetz · Luxembourg · IDEMMO`.

## Production checklist

1. Inspect the supplied IDEMMO assets before creating new visuals.
2. Preserve the gradient direction and the reference composition’s spacing.
3. Confirm no play circle is present.
4. For video, run HyperFrames check/render and inspect at early, middle, and final timestamps.
5. Deliver the MP4 plus the editable HyperFrames HTML source.

Reference assets are in `assets/`; detailed asset notes are in `references/assets.md`.
